# What we tried first

When an approach fails and we switch, add a row: idea, what happened, what we did instead.

| Idea | What happened | What we did instead |
|---|---|---|
| Standalone `perception/setup_gui.py`: interactive OpenCV tool to lock camera exposure, calibrate the grid homography, and sample cube colors | Camera turned out to have no software exposure control at all (confirmed by probing `.set()` then reading back the value on every property). Separately, `robot/` already had a working, more accurate camera pipeline (`robot/perception/`, 4.4mm mean placement error) that solved the same problem differently: it never tries to control exposure, it tunes HSV thresholds empirically to tolerate the overexposure. Its grid/tag geometry matched ours exactly even though measured independently. | Dropped `setup_gui.py`, `generate_grid_pdf.py`, and the regenerated grid PDF. Consolidating on `robot/perception/` as the one working camera pipeline instead of maintaining two. |
| Robot: keep the jaws pointing the same way at pick and place, so the cube never turns in the hand | Did not help: B2 runs with and without the turn landed on the same spot, 19 mm off; it also chose a 139 degree wrist roll for a turned cube, and the travel path needed an IK jump, so the task stopped | Rank grips by wrist roll (accurate near 0) and check each travel path while planning, falling back to the next grip |
| Robot: rank grips by room to spare first, wrist roll second | Run 19:33 took an 87 degree release to gain 1 mm of room (5 mm vs 6 mm preferred) and missed B2 by 23 mm | Rank by wrist roll first (under 30 degrees at the release), room second; any grip with room above 0 is already safe |
| Robot: stop the task when a block lands out of tolerance | A repeatable 19 mm miss ended runs that one more try would have fixed | Retry up to 2 times (AGENTS.md cap): pick the block from where it landed and aim off by the measured miss |
| Robot: clear a target by moving any block within 60 mm of it on both axes | On a 3x3 grid of 57 mm cells that zone covers every neighbouring cell, so there was nowhere to move blocks to | Measure the edge-to-edge gap instead: move blocks under 8 mm from the target (normal neighbours stand 9 mm apart) to the nearest empty cell |
